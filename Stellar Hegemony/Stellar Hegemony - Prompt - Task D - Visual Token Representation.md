# Stellar Hegemony - Prompt - Task D: Visual Token Representation (Large & Small)

**Task:** D  
**Part of:** Zone Points System Implementation Plan

---

## Prompt for Grok Build

Create visual tokens that can be attached to zones to display Primary and Secondary point values.

**Requirements:**

- Create two token types following the 1950s retro space / Jetson aesthetic:
  - Large token (Primary Points)
  - Small token (Secondary Points)
- Tokens should clearly display the numeric value.
- Tokens should be designed so they can be attached to zones on the HybridMap.
- At this stage, tokens should be visual only (non-interactive).

**Success Criteria:**
- Two distinct token styles exist (Large and Small).
- Tokens display the correct numeric value.
- Visual style matches the established retro space aesthetic of the game.
- Tokens are ready to be instantiated and positioned on zones.

**Scope:** Narrow — only the creation of the visual token assets and basic components. Integration comes in Task E.
